# ComfyUI workflows

Workflow files used by the Ad Creative Studio for variant generation. Save them in ComfyUI's
**API format** (Workflow > Export (API)), not the UI format.

Naming: `<purpose>.json`, for example `background_swap.json`, `upscale_4x.json`,
`placement_crops.json`.

For each workflow, add a short entry below listing the input node IDs the service fills in
and the open-weight models it needs, so it can run on a fresh ComfyUI install.
